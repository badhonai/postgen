# FLUTON — Your intent. Not your data.

Editable source for a new 15-second, 1920×1080, 60 fps Fluton film.

## Preview and render

Requires a compatible Node.js LTS installation and FFmpeg/ffprobe on PATH. Linux also needs Chrome Headless Shell's shared libraries (tested with libnss3, libnspr4, fontconfig and fonts-dejavu-core). Use the pinned lockfile; don't float motion-dom/motion-utils independently.

```bash
npm ci --ignore-scripts --no-audit --no-fund
npx remotion browser ensure
mkdir -p tmp/fluton-intent .cache/fluton-intent exports
npx remotion studio src/fluton-intent/index.tsx --port=3000 --no-open
```

The film already includes generated lettering, embedded exact logo assets and the original WAV. To render without editing/regenerating assets:

```bash
node scripts/qa-fluton-intent.cjs
node scripts/render-fluton-intent.cjs final
python3 scripts/master-fluton-intent.py
```

Mastering uses Python's standard library plus the installed FFmpeg binary. The final result is `exports/fluton-intent-15s.mp4`. Render intermediates/bundles live in `.cache/fluton-intent/` and are regenerable. `tmp/fluton-intent/` holds evidence.

## Editing

- Main artwork and pure frame-derived motion: `src/fluton-intent/FlutonIntent.tsx`.
- Composition: `src/fluton-intent/index.tsx`.
- Shared dimensions, rate and named cue frames: `src/fluton-intent/timeline.json`.
- Heavy/support phrase outlines: `src/fluton-intent/glyphs.json`; its generator is `scripts/prepare-fluton-intent.py`.
- Actual mark and wordmark: `public/fluton-intent/`; data-URI embedding and tint-only extrusion masks are generated by the same preparation script.
- Original music: `scripts/score-fluton-intent.py`. Its random seed is fixed. Edit shared cues before regenerating the music if changing major timing.

Optional asset regeneration / contact-sheet creation needs Python packages:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-fluton-intent.txt
mkdir -p tmp/fluton-intent .cache/fluton-intent exports
python scripts/prepare-fluton-intent.py
python scripts/score-fluton-intent.py
node scripts/render-fluton-intent.cjs states
node scripts/render-fluton-intent.cjs strips
node scripts/qa-fluton-intent.cjs
node scripts/render-fluton-intent.cjs final
python scripts/master-fluton-intent.py
python scripts/contact-fluton-intent.py
```

When adding text, add its phrase to the preparation script's appropriate weight group, regenerate outlines and reference the exact string in the component. Inter's WOFF2 files are variable fonts: the generator deliberately instances 900/600 before reading glyph paths.

## Stack and review boundary

Actual Remotion 4.0.542; Framer Motion 12.23.24 uses `motion.g`, explicit numeric frame styles and cubic Bézier curves. No browser `animate` timeline, CSS animation, Three.js, paid model API or hidden remote rendering requirement. Custom SVG projection handles the layered dimensional logo. This is a resolved sequence, not a seamless-loop deliverable.

See `exports/fluton-intent-build-notes.md` for exact final metadata, 44 inspected decoded-frame indices, audio measurements, iteration and limitations. Stills and technical audio checks do not establish continuous audiovisual review. The archive's QA evidence describes the exported master, not a promise that every future environment will render identical bytes.

## Asset / package rights

The logo and wordmark are supplied Fluton brand assets, not general-purpose open-source artwork. White fronts remain byte-for-byte unchanged. The Inter SIL OFL notice and asset provenance are retained under `public/fluton-intent/`. Music was authored procedurally for this film without samples. Dependency licenses, including Remotion's applicable license terms, remain separate from package metadata and asset rights.

This source archive intentionally excludes node_modules, browser binaries, credentials, older projects/films, render bundles and public creator-reference media. Root `SOURCE-MANIFEST.json` records every payload file's SHA-256; the manifest does not hash itself. Packaging is optional and uses the included `scripts/package-fluton-intent.py`.
