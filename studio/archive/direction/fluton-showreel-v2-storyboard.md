## Visual system
- Supplied white logomark and full wordmark, embedded in the HTML.
- Inter 600 and 800; flat green `#05DF72`, blue `#2B63D9`, black `#09090B`, white `#F8FAFC`.
- Fixed orthographic camera, persistent logo and transforming structural rails.
- Mathematical critically damped spring and exponential interpolation; no CSS animations, timers, or frame-history dependence.
- Directional speed-based logo trails and three-sample temporal motion blur.
- No crossfades, glow, lens flare, RGB split, particle bursts, or gradients.

## Build / render
```sh
python3 scripts/build-fluton-v2.py
npm install --no-save playwright
# Requires FFmpeg and Google Chrome at /usr/bin/google-chrome.
node scripts/render-fluton-v2.cjs beats
node scripts/render-fluton-v2.cjs render
node scripts/qa-fluton-v2.cjs
```
The `beats` pass renders all 64 beats plus the loop image and creates the reference-soundtrack WAV. The full render captures 5,760 subframes, integrates each group of three through FFmpeg `tmix`, outputs 1,920 frames at 60fps, and muxes stereo AAC audio. Heavy rendering is performed on the user-designated Box server.
