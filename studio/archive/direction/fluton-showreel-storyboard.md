# Fluton — Private by transformation

**Concept:** One persistent 24-piece system transforms from exposed data to encrypted geometry, folds into a confidential engine, becomes an interface, and returns to its first arrangement.

## Delivery specification
- 32 seconds · 120 BPM · 16 bars · 64 beats
- 1920 × 1080 · 60 fps · H.264 MP4 with AAC audio
- Inter only; green `#05DF72`, blue `#2B63D9`, black `#09090B`, white `#F8FAFC` (red token defined but unused)
- Fixed orthographic camera; no cuts, crossfades, camera shake, glow, lens flare, particle bursts, RGB split, or gradients
- Critically damped mathematical spring and exponential easing; velocity-directed trail plus 3-sample temporal integration

## Source and reproducibility
- `fluton-showreel.html` is self-contained, including the embedded font. `window.seek(t)` redraws the complete image from time alone. No CSS animations, timers, or frame history.
- `window.audio()` uses `OfflineAudioContext` at 48 kHz to compose and render a stereo WAV, with kick on every beat, noise hits at each 4-second chapter, bass, percussion, and a filtered riser into the 26-second climax bar.
- `scripts/build-showreel.py` builds the self-contained HTML from the editable source and original font.
- `scripts/render-showreel.cjs` uses Playwright and system Chrome. `beats` renders 65 frames (64 beats plus the loop check) and the WAV; `render` produces 5,760 subframes, blends each trio with FFmpeg `tmix`, renders four segments, concatenates, and muxes audio.

```sh
npm install --no-save playwright
# Requires system Google Chrome at /usr/bin/google-chrome and FFmpeg on PATH.
node scripts/render-showreel.cjs beats
node scripts/render-showreel.cjs render
```

## Visual QA
All 64 beat samples were reviewed in four contact sheets before the full render. Revisions included clipping-safe text transitions, fitting long headlines, moving the UI grid fully inside its enclosure, and replacing the initial corner-only 3D construction with true projected faces. The loop explicitly returns the image at 32 seconds to time zero. The last rendered frame also samples time zero.
