# Intake questions (ask every time)

Ask in **one short message**, with defaults, before any research or code. If the user already answered
something in their request, don't re-ask it — restate it as a default and move on.

| # | Question | Default if unanswered |
|---|---|---|
| 1 | What is the film about, and what single thing must a viewer remember? | — (must be answered) |
| 2 | Where will it be posted, and what aspect/duration? | 16:9, 30 s |
| 3 | Narration: voice, language, or silent? | **Liam** (`TX3LPaxmHKxFdv7VOQHJ`), English, narrated if a script exists |
| 4 | Which exact assets may I use (logos/files) and where are they? | only assets the user supplies |
| 5 | What must NOT be claimed? (testnet status, metrics, guarantees) | assume nothing unverifiable may be claimed |
| 6 | Who makes the visuals: solo, or Claude with a ZIP return? | solo |
| 7 | Which PostGen project receives the video, and what caption style? | ask; draft only |
| 8 | Anything already approved (script, voice, previous cut) I must keep? | none |

Then: research → script → **voice** → handoff → visuals → review → final → draft post.
