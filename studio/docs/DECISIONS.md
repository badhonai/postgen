# Production lessons retained in this lightweight rebuild

- One frame clock. Remotion + actual Framer Motion components/easing worked when values were frame-derived; importing a component alone is not an integration claim.
- Explicit swangle addressed backend-dependent edge variations in sampled fresh/reverse seek tests. This is workload-specific evidence, not a universal browser guarantee. The runner keeps that tested baseline.
- Keep matching Remotion versions and the pinned motion-dom/motion-utils pair; an earlier floating dependency mismatch broke bundling.
- Load fonts before capture. SVG outlines are an optional per-project choice for exact typography, not a mandate to generate hundreds of unused phrases.
- World-space clipping and near-lip layering fix insertion physics. A shape floating across a box is not a successful ballot drop.
- Removing a footer background can expose previously hidden off-screen content. Clip scene content, not the scene background, and adapt text contrast.
- Use genuinely different visual mechanisms throughout a film. An identical transition with changed copy/colors was explicitly rejected by the user.
- Original energetic BGM was liked; hiss/sweep transitions were rejected. Prefer dry/tonal accents while still matching the brief.
- Preserve exact user-selected narration and logos. No silent voice substitution; no unauthorized pitch/speed or billing changes. Recorded filename is not independent voice-identity verification.
- A supplied 52-second performance required a longer conform than a provisional 45-second plan. Duration is a production decision, not a reason to rush a voice.
- Original PCM → single final AAC encode; measure final encoded output. For visual-only changes, copy and verify the existing audio rather than re-encoding it.
- Frame sheets, ASR, loudness measurements and decoding are useful but not continuous listening/viewing or independent critique. Report the boundary.
- A benchmark favored local rendering for one old workload. Do not claim that result applies to all machines, GPUs, 3D or future films.

Historical films and the large source/research cache are intentionally outside this Git tree. These distilled lessons are not a claim that the new scaffold received a full production-film review.
