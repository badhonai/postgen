# Research distilled for reuse

Research date: 2026-11-09. This folder retains the important conclusions and immutable source pointers—not raw creator videos, screenshots, full repositories, catalogs or production exports.

## What was actually researched
Twelve repositories were pinned; an earlier private collection contained 275 selected text/code files and 29 SKILL.md entrypoints. Core sections and a few helpers were selectively reviewed, **not all files line-by-line or security-audited**. Catalog entries/prompt counts are not videos watched. No upstream application/plugin/build was executed merely to collect it. Community examples do not establish which model, tools or iteration count a creator actually used.

## Adopted synthesis
Four authored skills under .agents/skills translate the useful mechanisms into one workflow: direction, choreography, frame-safe engineering, sound/QA. They are explicitly read when relevant, not bulk-installed. Concept/coherence precedes effects; timing is per action/property; time is deterministic; sound follows meaningful cues; review claims require evidence.
