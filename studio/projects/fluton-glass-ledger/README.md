# fluton-glass-ledger

16:9 follow-up to the rejected 9:16 film, built from the direction notes archived in
`studio/archive/direction/`. 51.6 s, one persistent system, eight chapters, one sentence each.

- `src/film-data.json` — spec, palette, safe areas, scene timings (generated by `tools/align_voice.py`).
- `src/visual-system.tsx` — palette, type scale, springs/exponentials, `Label`, `Row`, `Note`, `Headline`.
- `src/Film.tsx` — the persistent frame, the 8-column grid, the progress rule, the scene registry.
- `src/scenes/*.tsx` — the eight chapters, one intent each.
- `production/` — script, voice, cues, score, mix, storyboard, fact check, delivery.
